# Phase 4 decisions

## P4-001 · Factual motion

Motion may amplify an existing state but may not invent one. RETURN waves require an FSRS-due graph node; RETRIEVE afterglow requires a real recent recall; selected paths require confirmed graph edges.

## P4-002 · RETURN haptics

A deliberate selection of a due node may use a two-part Web Vibration pattern (`9, 34, 9`) coupled to the existing sound toggle. Unsupported browsers remain silent. No separate haptics setting and no auto-vibration on page load.

## P4-003 · Decorative geometry is not memory data

Atmospheric orbit shapes use SVG ellipses rather than memory-node circles so tests, accessibility semantics, and the visual data model keep a clean distinction between ornament and actual remembered nodes.

## P4-004 · Session phases share the same language

Gold remains human/encoding/connection/return; cyan remains system/retrieval. Session phase choreography is CSS-only and has no influence on timing, scoring, FSRS, or mission composition.
