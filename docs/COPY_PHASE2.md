# ANITEW · Copy-Richtung Phase 2

Geprüfte Hauptzeilen:

1. **Your memory, trained.** — präzise, aber etwas technisch.
2. **Remember more.** — kurz, jedoch zu nah an einem generischen Leistungsversprechen.
3. **Remember what matters.** — persönlich und inhaltlich, ohne Leistungszahl.
4. **A place for what you want to keep.** — warm, aber für einen Hauptslogan zu lang.
5. **What matters, returns.** — eigenständig und nah am Wiederbegegnungs-Moment.

**Entscheidung:** Der bestehende Hauptsatz „Memory is a skill, not a gift.“
bleibt vorerst bestehen, weil Wissenschaftsseite und Produktentscheidung daran
hängen. „Remember what matters.“ wird die bevorzugte Kampagnenzeile für das
Personal Memory System. Kein Text verspricht allgemeine Gehirnsteigerung.
