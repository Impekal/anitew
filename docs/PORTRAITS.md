# Portrait photographs

186 distinct photographs are bundled with ANITEW under the Pexels License.
Each fictional training name has one fixed image across all four name pools,
including delayed reviews and missions. These labels and mission details do
not describe the photographed people. No endorsement is claimed.

Sources, photographers, downloaded-file hashes and resizing details are in
`public/portraits/manifest.json`. All selected candidates were visually reviewed
for distinguishability and crop; repeated photographs of the same apparent
subject were excluded. Selection includes young and older adults, varied skin
tones, hair, glasses, clothing, and indoor/outdoor backgrounds. These visual
observations are not demographic or identity labels.

## Offline and continuity

The 2.23 MB image set is precached during installation, including before a photo
has been seen. There is no CDN/API call or remote fallback at runtime. Unknown
imported names show a neutral question mark, never an unrelated person's photo.
Add future names and photos explicitly; never reshuffle existing assignments.
The switch from drawings to photos changes the visual cue once for existing
users. It does not delete history or reset FSRS state. Historical drawing and
new photo performance should not be presented as directly comparable evidence.
