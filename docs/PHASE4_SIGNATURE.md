# ANITEW Phase 4 — Signature Experience

Phase 4 is not a feature expansion. It gives the already factual Personal Memory System a sensory identity.

## Contract

1. **No invented memory state.** Motion, glow, sound and haptics may only represent states already proven by the graph, FSRS, or a real user action.
2. **Quiet is a state.** A calm Memory World is allowed to be beautiful without manufacturing activity.
3. **RETURN is recognition, not reward.** A due node may emit a slow warm return wave and a short two-part tactile cue when deliberately selected.
4. **RETRIEVE is an afterglow.** A recently recalled node may briefly transmit a cool signal through confirmed edges; it must decay again.
5. **Selection reveals structure.** Focusing a real node highlights only its confirmed edges. No decorative fake connections.
6. **One sensory language.** Gold means human/remembered/returning; cyan means system/relationship/retrieval. Session phases reuse this language.
7. **Reduced Motion is equal, not second-class.** Meaning remains visible when motion is disabled; animation is never the only carrier of state.
8. **Offline first.** No audio assets, remote visual assets or network-only effects are required for the signature experience.
9. **Performance remains a product feature.** Atmosphere is CSS/SVG, bounded, deterministic, and does not add animation loops in JavaScript.
10. **The user should remember the behavior, not an ornament.** The signature moments are: a memory is born, a connection draws, something genuinely returns, a recall travels through its world, and the system becomes quiet again.

## Phase 4 slice 1

- Memory World receives deterministic atmosphere and depth.
- Due FSRS nodes emit RETURN waves.
- Recently recalled nodes emit a short RETRIEVE wave.
- Selecting a node lights only confirmed connected edges.
- RETURN gains a subtle two-part vibration on platforms that support Web Vibration.
- Session phase markers use the same gold/cyan semantic language.
- All new motion is disabled under `prefers-reduced-motion: reduce` while factual state markers remain visible.
