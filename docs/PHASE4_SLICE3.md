# ANITEW Phase 4 · Slice 3 — Memory Landing

The signature moment is allowed to happen only when a personal memory actually returns.

- `recall` remains neutral: a memory prompt was resolved.
- `landing` fires only when the personal `memory` module contains at least one genuinely correct recalled item.
- The event lasts 900 ms and changes no score, FSRS schedule, graph truth, session duration, or progression.
- Sound, haptic and visual resonance represent the same factual event.
- If the last recall ends the session, the transient resonance carries into Summary instead of being lost between screens.
- Reduced Motion removes the expansion animation while preserving a quiet static state.
- Wrong or empty personal recall must never receive the landing cue.

The intended feeling is recognition, not reward: something that mattered disappeared, and the user brought it back.
