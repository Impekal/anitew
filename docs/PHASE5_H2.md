# Phase 5 H2 — Mission object location

A mission now carries a fifth factual bond: where the carried object is located in the scene.

- Existing room, object, time and restaurant draws remain deterministic and unchanged.
- The new location is generated only after those existing draws.
- The scene shows object and location together so the bond can be encoded visually.
- Object and location are stored and graded as separate facts.
- Location wording exists for DE/EN/FR/ES training content.
- UI copy is supplied through the existing dictionary layer, with English fallback for untranslated interfaces.
